# v0.1.0

First release of a Go BitTorrent client built as a portfolio and learning project.
The release binary targets Linux amd64.

## Features

- Single-file v1 torrents with HTTP/HTTPS trackers and IPv4 peers.
- Concurrent downloads from bounded peer groups, SHA-1 piece verification,
  reassignment after peer failures, and tracker refreshes.
- Uploads of verified pieces to incoming peers, availability updates during
  downloading, and continued seeding after completion.
- A CLI and Bubble Tea terminal UI sharing the same transfer engine, with live
  progress, transfer rates, peer counts, and keyboard cancellation.
- Existing output files are protected from overwriting. Partial output remains
  available after cancellation or failure.

## Getting started

Download `torrent-client-v0.1.0-linux-amd64.tar.gz` and `SHA256SUMS` into the same
directory, then run:

```sh
sha256sum -c SHA256SUMS
tar -xzf torrent-client-v0.1.0-linux-amd64.tar.gz
cd torrent-client-v0.1.0-linux-amd64
./torrent-client -torrent /path/to/input.torrent -output /path/to/output.bin
```

Add `-tui` for the terminal UI. Press `q` or Ctrl+C to stop and quit the TUI;
Ctrl+C stops the CLI. Seeding is enabled by default; use `-seed=false` to stop
transferring after the download finishes. The TUI retains its final screen until
dismissed. See the included README for all options.

## Known limits

- Restarting does not resume partial downloads; an existing output path is
  refused, including a partial file from a previous run.
- UDP trackers, magnet links, DHT/PEX, announce tiers, multi-file and v2/hybrid
  torrents, IPv6 peers, automatic port mapping, pause/resume, and request
  pipelining are deferred.
- Uploads are served through incoming connections. Peer preparation is
  sequential before each download batch; newly discovered peers are candidates
  for subsequent batches.
- In-flight tracker requests and outbound peer preparation use bounded timeouts
  rather than immediate context cancellation.
- Linux amd64 is the verified platform. Public incoming connectivity may require
  manual router configuration. TUI mode requires an interactive terminal.
